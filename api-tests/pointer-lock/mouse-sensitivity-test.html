Mouse / Pointer Coordinate Test

Listens to all move event types at once. Spawns cursors for each event stream × coalesced/uncoalesced, driven by movementX/movementY.

Instructions

  1. Optionally enable unadjusted pointer lock, then click Enter pointer lock (Esc to exit). Check the status block for whether unadjusted movement was granted.
  2. Left-click the tracking area to spawn cursor canvases in columns (one stream per column) along the left.
  3. Move the mouse. Each cursor accumulates movementX/movementY from its event stream (raw vs coalesced).
  4. Solid labels = uncoalesced (the event as delivered). Dashed labels = expanded getCoalescedEvents(). mousemove has no coalesced stream.
  5. Click again to respawn at the left. Right-click (or Clear) removes cursors.

Event streams

mousemove
pointermove …
pointerrawupdate …
coalesced variant (dashed label) …

All supported streams are listened to simultaneously after spawn.

Options

Pointer lock

Pointer lock: off
Unadjusted movement: n/a

Actions

Diagnostics

Diagnostic capture: idle

While pointer-locked, press S to start/reset a trial and E to stop and print it. Console API: pointerLockDiagnostics.start("label") and pointerLockDiagnostics.stop().

Notes

  • Only relative movementX/movementY drive the cursors.
  • Coalesced movementX/movementY semantics differ across browsers / versions (notably older Firefox).
